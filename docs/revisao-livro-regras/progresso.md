## Denominador explicável

- Universo desta versão: **27 unidades funcionais**, LR01 a LR27, distribuídas em nove partes temáticas.
- Cada ID vale uma unidade, independentemente do número de páginas ou entradas de catálogo. É indicador de unidades, não medida de esforço.
- Numerador: somente as dez unidades marcadas implementado, no recorte fechado de cada uma.
- Parciais não recebem meio ponto. Pendentes de verificação não são tratados como funcionalidades ausentes.
- Mapeamento: 27/27 unidades possuem tema, localizador de fonte, evidência ou localizador de código e limite da conclusão.

## Atualização do placar

Ao ampliar o inventário, preserve os IDs e registre a mudança do universo. Se uma unidade se dividir, retire-a do denominador ativo e identifique as sucessoras, sem contar pai e filhas simultaneamente. Recalcule a tabela a partir dos estados nas partes. Não compare percentuais entre universos diferentes como se fossem avanço de implementação.

Um status implementado só cobre o critério pequeno que foi lido. Para elevar uma unidade ampla, percorra fonte, configuração, coletor, efeito, consumidor, resultado, sessão e interface aplicáveis. Registre decisões da fila, versão do código e provas reais. A evolução dessa análise não altera automaticamente os estados da campanha de automação.
