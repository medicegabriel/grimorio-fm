# Prompts para os nove lotes

Cada arquivo contém um prompt completo para copiar em um chat novo do responsável indicado. Não é necessário copiar um preâmbulo separado. Os prompts são instruções de execução futura, sua criação não inicia os lotes.

Todos exigem uma checagem antes de alterar o produto: confrontar livro, decisões, código atual e reprodução válida, classificar falsos positivos e apresentar o diagnóstico. Só então implementar o escopo confirmado, sem aprovação genérica adicional. Dúvidas materiais de regra bloqueiam apenas sua parcela.

A fila e os estados continuam exclusivamente em [a-fazer.md](../../a-fazer.md#divisão-de-execução-codex-e-claude-2026-10-29). Os relatórios de entrega solicitados pelos prompts guardam evidências, não outra fila.

## Ordem de abertura

Comece por CX1 e CL1, coordenando a identificação da base e a reserva dos arquivos. Depois libere as operações do Claude para os consumidores do Codex. Os números não impõem uma sequência cega: as parcelas de temporários em CX4, por exemplo, podem precisar vir antes de consumidores em CX2/CX3.

Não abra os nove chats para editar simultaneamente a mesma árvore. Um editor por vez nos arquivos compartilhados. Consulte entregas reais e decisões recentes antes de cada novo lote. Nenhum prompt autoriza commit, push, promoção do G2 ou reabertura de decisão já tomada.

Os casos N01 a N15, as contagens e os resultados da análise de 2026-10-29 são referências históricas. Um prompt não transforma um achado antigo em obrigação de modificar um código que já esteja correto.
